Загрузи собственные или переведённые заклинания. Импорт сначала сохраняется как черновик в этом браузере. Чтобы игроки увидели записи, скачай общий файл и замени им custom-spells.json в GitHub-репозитории расширения.

В черновике: 0 заклинаний Поддерживаются JSON, CSV, Markdown и TXT.
Формат файла для импорта

Для JSON используй массив объектов или объект вида { "spells": [...] }. Укажи name, level, school, classes и description. Для броска урона используй damageFormula, а для лечения — healingFormula или heal_at_slot_level. Для учёта модификатора характеристики добавь healingIncludesAbilityModifier: true. Формулы поддерживают d и русскую запись к (например, 2к8+3). Для своих переводов используй nameRu, descriptionRu и higherLevelRu.
