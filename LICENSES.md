# Источники и лицензии

## Owlbear Rodeo SDK

The Owlbear Rodeo SDK is used to determine the current Owlbear Rodeo role. The SDK package is published under the MIT License: https://github.com/owlbear-rodeo/sdk

## Open D&D rules data

The built-in spell catalog is retrieved from the D&D 5e SRD API (`https://www.dnd5eapi.co/`). The API implementation is MIT-licensed. The underlying rules data is restricted to the relevant System Reference Document version.

- SRD 5.1 and SRD 5.2: Wizards of the Coast LLC.
- License: Creative Commons Attribution 4.0 International (CC BY 4.0).
- SRD page and attribution details: https://www.dndbeyond.com/srd
- API documentation: https://docs.dnd5eapi.co/

This extension does not bundle the full Player's Handbook spell catalog or scrape DnD.su.
