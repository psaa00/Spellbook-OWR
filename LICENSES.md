# Источники и лицензии

## Owlbear Rodeo SDK

The Owlbear Rodeo SDK is used to determine the current Owlbear Rodeo role. The SDK package is published under the MIT License: https://github.com/owlbear-rodeo/sdk

## Open D&D rules data

The built-in spell catalog is retrieved from the D&D 5e SRD API (`https://www.dnd5eapi.co/`). The API implementation is MIT-licensed. The underlying rules data is restricted to the relevant System Reference Document version.

- SRD 5.1 and SRD 5.2: Wizards of the Coast LLC.
- License: Creative Commons Attribution 4.0 International (CC BY 4.0).
- SRD page and attribution details: https://www.dndbeyond.com/srd
- API documentation: https://docs.dnd5eapi.co/

This extension does not bundle the full Player's Handbook spell catalog or scrape DnD.su.

## Переводы SRD

Переводы текстов заклинаний, подготовленные для этого расширения, создаются независимо по англоязычным материалам SRD 5.1 / SRD 5.2. Указание `nameRu`, `descriptionRu` и `higherLevelRu` обозначает адаптированный перевод, а не копирование переводов стороннего сайта. DnD.su может использоваться для сверки русскоязычной терминологии и названий; его текстовые описания не импортируются и не считаются автоматически открыто лицензированными.

При распространении адаптированного SRD-контента необходимо сохранять атрибуцию Wizards of the Coast LLC, ссылку на соответствующую версию SRD и Creative Commons Attribution 4.0 International (CC BY 4.0), а также отмечать, что текст переведён/изменён. Официальные сведения и формулировки атрибуции: https://www.dndbeyond.com/srd


## Русская локализация SRD 5.1

Файл `srd-2014-ru.json` содержит самостоятельно подготовленные русские переводы названий, описаний и полей заклинаний, основанные на System Reference Document 5.1 (SRD 5.1) Wizards of the Coast LLC. SRD 5.1 доступен по Creative Commons Attribution 4.0 International (CC BY 4.0): https://www.dndbeyond.com/srd и https://creativecommons.org/licenses/by/4.0/.

Атрибуция: System Reference Document 5.1 (SRD 5.1) от Wizards of the Coast LLC; используется по лицензии CC BY 4.0. Русский перевод и адаптация полей подготовлены для проекта Spellbook-OWR. Перевод является производной адаптацией открытого SRD и не является официальным переводом Wizards of the Coast.

Указанные на сайте DnD.su названия могут служить терминологическим ориентиром; русские описания заклинаний с DnD.su в этом проекте не копируются. Дистанции сохраняются в исходных единицах SRD — футах; футы не пересчитываются в метры.
