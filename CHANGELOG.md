# Changelog

## 1.1.1
- Исправлено ожидание готовности SDK Owlbear Rodeo: таймер больше не считает SDK готовым, если событие `onReady` не пришло.
- Отправка бросков повторяется до трёх раз при временной ошибке `not ready`.
- Для Broadcast используется документированный вызов с каналом и данными, без лишних параметров.
- Фоновая страница подписывается на сообщения только после фактической готовности SDK.

# История изменений

## 1.1.0 — броски урона

- Добавлены кнопки броска урона в карточки заклинаний, если источник содержит структурированные формулы SRD или пользовательское поле `damageFormula` / `Урон`.
- Поддержаны формулы `NdM`, `dM`, несколько групп костей, целые модификаторы и отрицательные модификаторы.
- Для SRD используются формулы по уровню ячейки и уровню персонажа, когда они опубликованы API.
- Результаты броска отображаются в карточке истории и рассылаются через OBR Broadcast.
- Добавлена фоновая страница с уведомлением OBR, чтобы получать броски, когда окно книги заклинаний закрыто (расширение должно быть включено в комнате).
