# Changelog

## 1.2.0
- Добавлен отдельный бросок исцеления, не смешивающийся с бросками урона.
- Поддержаны поля SRD API `heal_at_slot_level`, `healingAtSlotLevel`, формулы пользовательских заклинаний и автоматическое осторожное извлечение лечебных костей из описания.
- Добавлен ввод модификатора заклинательной характеристики для заклинаний, чьё лечение зависит от него.
- Броски исцеления синхронизируются через отдельный тип Broadcast и показываются в журнале/уведомлениях.
- Добавлена поддержка собственных русских переводов через поля `nameRu`, `descriptionRu`, `higherLevelRu`; английское оригинальное название остаётся доступно поиску.
- В пример JSON добавлены «Лечащее слово» и «Лечение ран» с русским текстом и формулами исцеления.


## 1.1.2
- Добавлена проверка активной игровой комнаты через `OBR.room.id`: в лобби отображается локальный режим подготовки, который не считает пользователя участником комнаты.
- Отправка бросков через Broadcast выполняется только внутри комнаты; вне комнаты бросок считается локальным без ошибки `not ready`.
- Добавлена поддержка `damage_dice` в структуре SRD, CSV с русскими заголовками без учёта регистра и автоматическое распознавание нескольких формул урона в описании (русский и английский текст).
- Версионирован кэш SRD, чтобы старые записи без новых полей урона были загружены заново; локальные черновики при этом сохраняются.
- Фоновый слушатель Broadcast не запускается в лобби без комнаты.
- В лобби доступен отдельный локальный режим подготовки: импорт и черновик работают в этом браузере, но данные не транслируются и броски не рассылаются. В игровой комнате роль определяется через `OBR.player.getRole()`; игрокам мастерские инструменты скрыты.

## 1.1.1
- Исправлено ожидание готовности SDK Owlbear Rodeo: таймер больше не считает SDK готовым, если событие `onReady` не пришло.
- Отправка бросков повторяется до трёх раз при временной ошибке `not ready`.
- Для Broadcast используется документированный вызов с каналом и данными, без лишних параметров.
- Фоновая страница подписывается на сообщения только после фактической готовности SDK.

# История изменений

## 1.1.0 — броски урона

- Добавлены кнопки броска урона в карточки заклинаний, если источник содержит структурированные формулы SRD или пользовательское поле `damageFormula` / `Урон`.
- Поддержаны формулы `NdM`, `dM`, несколько групп костей, целые модификаторы и отрицательные модификаторы.
- Для SRD используются формулы по уровню ячейки и уровню персонажа, когда они опубликованы API.
- Результаты броска отображаются в карточке истории и рассылаются через OBR Broadcast.
- Добавлена фоновая страница с уведомлением OBR, чтобы получать броски, когда окно книги заклинаний закрыто (расширение должно быть включено в комнате).


## 1.3.0 — Начальная русская локализация SRD 5.1

- Добавлен файл `srd-2014-ru.json` с первой партией из 10 самостоятельно переведённых заклинаний SRD 5.1.
- Добавлена автоматическая загрузка локализации и сопоставление записей по английскому названию.
- Переведены названия, описания, время накладывания, дальность, компоненты, материальные компоненты и длительность для первой партии.
- В описаниях сохранены футы: расстояния не конвертируются в метры.
- Добавлена атрибуция SRD 5.1 под CC BY 4.0.
